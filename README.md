# dev-finder 🔍

Buscador de perfis do GitHub - Angular 19 + Tailwind CSS + GitHub API

**Live:** https://dev-finder-olive.vercel.app/

## 🚀 Tech
- Angular 19 (standalone, signals)
- Tailwind CSS
- Vercel

## ✨ Features
- Busca por username com estado vazio
- Card de perfil + stats
- Grid de repos recentes com linguagem e stars
- Loading e erro tratados

## ▶️ Rodar local
npm install
ng serve
